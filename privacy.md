# Privacy Policy - Haber Shorts

Last updated: November 9, 2026

Haber Shorts is a personal, single-user tool operated by Ozan Irmak (ozanirmak@gmail.com).

Data accessed: The app uses Google OAuth only to upload videos to the owner's own YouTube channel (scope: youtube.upload). It uses the Instagram API only to publish Reels to the owner's own Instagram account.

Storage: OAuth tokens are stored only on the owner's personal computer. No data is sold, shared with third parties, or used for advertising.

Third-party users: The app does not collect data from any other person.

Revoking access: Access can be revoked at any time at https://myaccount.google.com/permissions and in Instagram settings.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact: ozanirmak@gmail.com
